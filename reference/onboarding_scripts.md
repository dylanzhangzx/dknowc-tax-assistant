# 开通引导与话术（onboarding_scripts）

## S1 · 检索有价值但无 Key（initialize.py 返回 guide_message 时转述，要素不删改）

三段式：价值 → 开通方式 → 退路+样例钩子。

> 这个问题涉及税收政策和具体标准——税率、扣除标准、优惠条件按年度调整，凭印象答容易拿旧口径当现行政策，直接影响申报和缴税。开通权威检索后，每条结论都带政策原文出处、文号与日期，可点开核验，还会附一份可点击的溯源报告。
>
> 开通是免费的：注册即赠送 10 万积分，完成实名认证再送 10 万积分。只需手机号收一次验证码——约 10 秒，不用自己填注册表，剩下的我来办；手机号仅用于本次验证，不会有营销骚扰。
>
> 也可以先不开通：我先基于已有知识给你一版初步回答，涉及税率、扣除标准、优惠期限的地方逐条标注"依据待核验"，并说明未联网检索、口径可能过期。想先看看开通后检索结果和溯源报告长什么样，我可以发你示例看看。

要点：先说价值再说权益；手机号在用户同意开通后才索要；不催促。

## S2 · 索要手机号

> 请把你的手机号发我，我用它帮你注册检索账号并发一条注册验证码（手机号仅用于本次注册验证，不发营销短信、不打营销电话；验证后只在本机保存一个访问凭证，你的问题和材料不会上传）。

收到手机号后立即脱敏展示（<脱敏手机号>，形如 138****XXXX）。口径如实：手机号经命令行参数传给本机注册脚本（会短暂出现在本机进程列表）；对话与报告中只出现脱敏形式。

## S3 · 注册链路（register_key.mjs，参数以脚本实际签名为准）

```bash
# 第一步·领题/发码：优先走文字题（题目只给 agent，不进对话），平台回退时自动走短信直发
node scripts/register_key.mjs challenge --phone <手机号>
# 第二步·答题（文字题流）：题目是算术题，答案为非负整数；由 agent 计算，不问用户
node scripts/register_key.mjs answer --phone <手机号> --answer <非负整数>
# 第三步·注册取 Key：验证码来自用户收到的短信，只能由用户提供
node scripts/register_key.mjs register --phone <手机号> --vcode <6位验证码>
# 补写（仅当 register 输出 persistFailed=true 时：密钥已在本机临时保管文件里，0600、30 分钟内有效。
# 先修复配置目录可写，再运行 persist——它自动从保管文件恢复并正式落盘，成功即删保管文件）
node scripts/register_key.mjs persist
```

- `pending:true`（deliveryStatus PENDING）不是错误：账号已建、密钥准备中，等用户示意后同参数重试一次（短信码 5 分钟有效），不要重新注册、不要重新发码；
- 验证码只能由用户提供，agent 不猜测、不重试超过 2 次；
- register 成功时 Key 自动写入 `~/.config/dknowc/api_key`（0600、原子替换），stdout 只出掩码——**任何情况下不从输出里找明文 Key**；
- 写入失败（persistFailed=true、pendingKeySaved=true）时按输出 user_message 引导：修复配置目录（常见：目录被占用/权限不足）→ 用户说"重试写入" → 跑 `persist`（recoveredFromPending=true 即恢复成功）；pendingKeySaved=false（连保管文件都写不下）才走网页方式；全程不把明文 Key 打进对话；
- 成功后重跑 `initialize.py` 确认 `ready=true`，再回到原问题。

## S4 · 检索失败/接口异常（不承诺、不伪装）

> 刚才检索没有取到结果，我重试了一次仍未取到。为避免拿不确定的口径误导你，这个问题我先按"依据待核验"给你一版分析，稍后你可以再让我重试检索。

禁止：静默换标签/删标签重查后当作正常结果；把"本次未召回"说成"没有相关政策"。

## S5 · 超范围问题

- 港澳台/外国税法：如实说明"港澳台及外国税法不在覆盖范围"；只答内地一侧义务（用库内依据，如内地个税居民规则、避免双重征税安排的内地执行文件），**不引用外部网页展开域外规则、不做域外计算**；
- 税务筹划方案/涉税鉴证：说明"提供政策依据核对，不出筹划方案与鉴证意见"；
- 社保：可以查（相邻领域），答案标注"以当地社保经办口径为准"的适用边界。

## S6 · 环境缺失（env_message）

> 检测到本机开通检索还差一个小程序环境（约 1 分钟，只装一次），我现在装好可以吗？

不暴露组件名（node 对用户无意义）；用户同意后再装；拒绝则走 S1 的"先不开通"分支。

## 通用禁则

- 不把 Key 写进任何文件、报告、对话；
- 不向用户暴露接口内部字段名（label_zero/validityStatus/encryptedFileId…）；
- 不承诺"100% 准确/覆盖全部政策"——说"每条结论可溯源，检索不到的如实说明"。
